## 3. API 依赖

客户端通过 `core-activation` 调用（需 delta-api ≥ M011 已上线）：

- `GET /api/v1/activation/cards/purchase-options`
- `GET /api/v1/activation/status` → `planCode`、`daysRemaining`、`accessExpiresAt`
- `POST /api/v1/activation/cards/redeem`

Header 与既有激活一致：`X-Device-Id`、`X-Client-OS: ANDROID`、`X-Client-Channel: official`、`X-App-Package-Name`（APK 维度）等。

## 5. 与旧版 1.0.1 差异

| 项 | 1.0.1 | 1.0.2 |
|----|-------|-------|
| 购卡 | 单链 `purchase-url` | 多规格 `purchase-options` |
| 已激活展示 | 无剩余天数 | 规格 + 剩余天数 / 永久 |
| 法律 | v2 | v3（限时访问、续费说明） |
| 永久卡 UI | 无促销角标 | 可选「限时4折」 |

旧版 APK 仍可激活；未展示多规格与剩余天数不影响服务端权益计算。
